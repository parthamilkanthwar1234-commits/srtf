Operating Systems Theory & Formal Equations

Formal definitions, mathematical formulas, Gantt derivation, and starvation analysis.

1. Algorithm Formal Definition

Shortest Remaining Time First (SRTF) is the preemptive variant of the Shortest Job First (SJF) scheduling algorithm. At every time unit t, the CPU scheduler selects the process from the Ready Queue that requires the least remaining execution time to complete.

Preemption Condition: Remaining(P_new) < Remaining(P_running)

2. Fundamental Scheduling Metrics

Turnaround Time (TAT) TAT = CT − AT
Waiting Time (WT) WT = TAT − BT
Response Time (RT) RT = First CPU Time − AT
CPU Utilization (%) (Σ Burst / Makespan) × 100%

3. Provable Optimality

By Smith’s Rule and the exchange argument, scheduling ready jobs in monotonically increasing order of remaining execution time minimizes the sum of completion times: Σ CTᵢ = minimum. Dividing by n minimizes both the average Turnaround Time (TAT) and average Waiting Time (WT). No uniprocessor scheduling algorithm can achieve a strictly lower average waiting time on identical workloads.

4. Starvation & The Aging Solution

The Starvation Problem: If shorter processes continuously arrive into the ready queue, longer processes (e.g., massive batch tasks) can be repeatedly preempted and postponed indefinitely.

The Aging Technique: Real OS kernels (like Linux CFS or Windows scheduler) gradually decrease the effective remaining time or boost the priority of aging waiting tasks over elapsed time, guaranteeing finite completion.
